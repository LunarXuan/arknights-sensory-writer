# 盲测与迭代 v7

## 推荐测试

选择 3–5 名作者过去没有写过、且能确认成年或仅采用非性化模式的干员。只给角色名与需要分析的形态，让 Skill 自行研究并成文。

至少保留一轮“不提供额外文风提醒”的盲测，才能判断 Skill 本身是否已经学会当前风格。

## 评分维度（0–3）

- 角色特异性：是否只有这个角色成立。
- 设定消化：设定是否自然存在于正文，而不是资料汇报。
- 视觉落地：装备细节是否准确并进入因果。
- 感官中心：鞋袜、足部、气味是否真正占据正文核心，而不是只出现一小段。
- 感官层次：鞋、袜、足部、材料、气味、时间变化是否足够具体。
- 动态过程：是否把结论写成动作/时间过程。
- 自然分段：是否以完整自然段为主，既不是一句一段，也没有长段/单句段机械交替。
- 异常条件：低气味角色若需要扩展，是否通过合理压力场景变化而非硬造。
- 角色反应：特殊状态是否引发符合性格的察觉、反应和处理。
- 结构自然：是否有主线但不过分模板化。
- 句法节奏：长短句、停顿、反问、转场是否接近作者。
- 隐形叙述者：是否避免“我/我们”和元分析。
- 角色主题：比喻、场景、结尾是否从人物自身生长，并服务感官中心。
- 创意增量：遇到历史“没思路型”角色是否主动找出新切口。
- 事实边界：是否区分官方与推演。
- 安全边界：年龄和表达强度是否正确。

总分 48。

## 风格失败诊断

### 像分析报告

症状：

- “官方档案中”“从精二立绘看”。
- 每段都先解释资料再得结论。

修复：读取 `current-style-overrides.md`，把研究信息全部改写成世界内叙述。

### 变成角色文学短篇，鞋袜和气味太少

症状：

- 开头人物设定很多。
- 中间大段写关系、回忆、成长、哲思。
- 真正涉及鞋袜、足部和气味的内容只集中在一两个很短片段。
- 删掉感官段以后，文章仍然基本完整成立。

修复：

1. 暂停继续扩写角色剧情。
2. 读取 `sensory-reasoning.md` 建立 sensory map。
3. 至少补出两个内容充实的自然段：一段写鞋袜/穿着过程，一段写脱下后的足部与气味层次/时间变化。
4. 让后续人物主题建立在这些具体感官之上。

### 段落节奏过度设计 / 一句一段 / 长短 ABAB

症状：

- 大量独立短句段。
- 一个动作被拆成四五个自然段。
- 连续出现“短句。换段。短句。换段。”。
- 更隐蔽的情况：一段很长，下一段只有一句；接着又长、又一句，重复形成 ABAB。

修复：读取 `prose-rhythm.md`，先看段落轮廓，不看内容。把只承担承上启下功能的单句并入前后段；段落只在语义/场景真实变化时切开。短句保留在段内，不把“长短对比”当排版模板。

### 没有“作者感”

症状：

- 因果正确但句子很平。
- 没有自然反问、停顿、自我修正或轻微跑题。

修复：读取 `prose-rhythm.md`，再选 2–4 个 `prose-excerpts.md` 近邻样本重写；至少一个样本应为感官密度高的段落。

### 只像用词，不像思路

症状：

- “当然/不过/恐怕”很多，但还是模板。

修复：删掉一半口头禅，增加角色专属变量、鞋袜具体细节和真实发生过程。

### 角色可以替换

修复：运行角色特异性检查和灵感扩展器；新找到的设定必须进一步回答“它如何改变鞋、袜、足部或气味”。

### 太规整

修复：允许受控旁逸；让一个物件、关系或兴趣自然带出第二幕，但旁支需要继续承载题材核心。

### 低气味角色一直过于平淡

症状：常态推导正确，但文章从头到尾都只剩“清爽、轻微、没什么味道”，缺少变化。

修复：先确认低气味是否属于可被环境打破的常态条件。若是，读取 `exception-scenarios.md`，选择一个角色自然的高负荷或清洁受限场景，并把“角色察觉 -> 反应 -> 处理”写进去。若是非实体/无真实代谢等稳定设定，则不要硬加汗味。

### 太短

先判断是否真的已经完成。如果只是没找到切口，继续研究，不把历史短文当长度偏好；优先补感官层次而不是泛泛加背景。

## 核心回归测试

每次更新后至少检查两类角色：

1. **主题特别强的角色**：防止模型被“记忆、尘埃、通讯、故乡”等漂亮主题带走，忘记鞋袜与气味。
2. **气味合理偏轻的角色**：先验证常态基线，再测试模型能否在合理时加入一次压力场景，并让角色产生符合性格的反应。
3. **段落节奏回归**：专门检查是否出现“长段/单句/长段/单句”规律交替。

## 迭代优先级

用户反馈“哪里不像”时，按顺序更新：

1. `current-style-overrides.md`
2. `prose-rhythm.md`
3. `exception-scenarios.md`
4. `sensory-reasoning.md`
5. `prose-excerpts.md`
6. `style-profile.md`
7. `narrative-patterns.md`
8. `sample-index.md`

领域事实规则有新增时再修改其他参考文件。
## 量化回归测试

对盲测输出额外记录：平均句长、中位句长、句长标准差、`<=15`/`<=20` 短句密度、短单句段比例、ABAB 四段窗口数。

重点观察两类失败：

1. **碎句漂移**：`<=15` 字句明显高于约 20%，即使主题和内容正确，也会显得不像作者。
2. **段落打拍子**：二三十段里反复出现 `长段 -> 短单句 -> 长段 -> 短单句`，即使每个自然段本身通顺，也应视为格式层失败。

使用 `scripts/style_meter.py` 做同口径记录，便于不同 Skill 版本之间回归比较。


## v7 模式矩阵回归

至少对同一位已确认适合测试的角色做三次短回归，确保旋钮真的正交：

1. `literary + light`：应更柔和、意象更多，但不能丢失鞋袜与感官逻辑。
2. `professional + medium`：应明显呈现“简短背景 -> 连续深挖 -> 同人延伸”，中间分析最完整。
3. `professional + strong`：应在同一专业结构上增加积累、残留、材料混味和清洁难度，而不是改成另一种文风。

另任选一次 `literary + strong`，确认“文艺”不会被误解为“轻口”。

成人恋物开关单独测试：换到新角色时必须恢复关闭/重新验证年龄，不能因上一角色开启而继承。

## v7 重点失败诊断：分析仍然零散

症状：

- 中间虽然写了很多鞋袜和气味，但每段是不同模块。
- 一段材质，一段人物背景，一段环境，一段装备记忆，彼此没有连续因果。
- 读者记得“点很多”，却没有感到一个状态逐步形成。

修复：

1. 回到 `professional` 的 sensory map。
2. 选一个最主要的穿着场景，不急着换场景。
3. 让每段开头承接上一段留下的物理状态或动作结果。
4. 先完整写到脱鞋/放置/清洗，再决定是否引入第二场景。
5. 把没有改变主链的背景和知识删除或挪到同人延伸。


## v7 固定文风底座回归

同一角色至少测试 `literary + light`、`professional + medium`、`professional + strong` 三组。除了内容权重和感官深度变化外，三组输出的句长分布与自然段习惯应保持同一作者底座。

重点检查：

1. 文艺模式没有因为意象增加而出现大量短句、单句段或诗歌式断行。
2. 专业模式没有因为“三阶段逻辑”出现固定三块排版或阶段间单句过门。
3. `style_meter.py --strict` 对每组输出都不报告 L-S-L/ABAB 等硬失败。
4. 若只有某一种模式反复触发段落轮廓失败，优先修 `controls-and-modes.md` 的模式描述，而不是降低全局文风约束。
