# 当前风格硬约束 v7

这些规则代表作者当前明确偏好，优先级高于历史文章中的旧习惯。若历史样本与本文件冲突，以本文件为准。

## 1. 研究在后台，成文不展示检索过程

默认禁止在正文里使用以下元叙述：

- “根据官方档案……”
- “档案中提到……”
- “PRTS显示……”
- “设定集里写到……”
- “从初始立绘来看……”
- “从精二立绘可以看到……”
- “第二张图中……”
- “这套皮肤立绘……”

正确做法：先查清，再直接把事实写进角色世界。

例如后台确认“角色长期生活在寒冷地区、鞋内有保暖结构”，正文直接写：

> 常年行走在寒冷环境里，这样一双厚实的鞋显然不是为了装饰。真正麻烦的是，一旦活动起来，原本负责保温的结构也会把热量留在里面。

不要写成：

> 根据官方档案，她生活在寒冷地区；从精二立绘可以看到鞋子很厚。

## 2. 默认使用隐形叙述者

尽量避免：

- 我
- 我们
- 笔者
- 在我看来
- 我觉得
- 个人认为
- 让我们来看看
- 接下来让我分析

允许有鲜明态度，但把作者本人藏起来。

优先使用自然判断、反问、假设和动作推进，例如：

- “那么，问题也就来了……”
- “不过事情显然没有这样简单。”
- “倘若只是如此，反倒没有多少意思。”
- “想象一下……”
- “当然……”
- “不得不说……”

## 3. 不要写成来源报告

正文不是研究笔记。不要使用：

`来源 -> 引文 -> 解释 -> 结论`

而要使用：

`角色世界 -> 行为/场景 -> 鞋袜与身体过程 -> 气味/触感结果 -> 人物意义`

用户若要求出处，在正文之外另附“资料依据”。

## 4. 形态标签只用于内部解析

内部可以精确区分 base / alter / initial / E2 / skin。

正文优先写：

- “如今的她……”
- “多年以后……”
- “万圣夜那晚……”
- “那次联动拍摄时……”
- “换上更正式的一身衣装后……”

不要反复写：

- “精二立绘中……”
- “异格立绘里……”
- “这张皮肤里……”

只有用户明确要求做立绘分析报告时，才可以显式使用这些标签。

## 5. 历史原文不是绝对规范

历史文章可能包含：

- “让我们来看看”
- “从立绘中可以看出”
- “在档案中……”
- 贴吧式读者称呼
- 当时偶发的第一人称

这些可以帮助理解作者过去的节奏，但不应在当前生成中自动复现。

## 6. 鞋袜、足部与气味必须保持题材中心

这是当前保留的硬约束。人物背景、成长、关系和主题是为了让鉴赏只属于当前角色，不能反过来吞掉鞋袜与足部感官描写。

正文中段应持续出现并展开以下内容中的多个维度：

- 鞋型、鞋口、鞋垫、内衬、材质、固定方式和实际穿着感。
- 袜子/丝袜/裤袜的厚薄、吸湿、贴合、摩擦、潮湿和残留。
- 足部的温度、干湿、摩擦、压迫、黏腻、放松、局部差异等状态。
- 气味的组成、浓淡、扩散、释放、时间变化、材料混味和清洗后的变化。
- 重复穿着、晾晒、清洗、鞋内残留等装备历史。

不要求每篇把以上全部写一遍，但不能只有“鞋子有些闷”“脚上有一点味道”两三句便离开主题。

内部做一次删除测试：**把鞋袜、足部和气味相关内容删掉以后，如果剩下部分仍然能独立成为一篇完整的人物小传、角色散文或剧情短篇，说明题材中心已经丢失，必须重写。**

特殊角色即使合理结论是“几乎没有气味”，也不能因此转去只写人物哲思。应当把“为什么没有”写具体：没有汗水、没有升温、没有织物吸湿、没有旧鞋残留、没有脱鞋后的热气释放，或其他角色专属原因。

## 7. 自然分段，禁止“一句一段”与机械长短交替

v2 对“短句落点”的强调过强，容易把每一句都拆成独立段落。当前目标不是这种排版。

优先规则：

- 一个自然段围绕同一个小场景、动作链、因果链或感官层次展开。
- 自然段长短由语义决定，不按“这一段长、下一段就短”来做人为对比。
- 短句优先放在段落内部制造节奏，不需要单独换段。
- 单句段只用于真正独立的停顿、转场、反转、对话或情绪落点；若并回相邻段仍然自然，就必须并回去。
- **禁止规律性 ABAB：长段 -> 一句短段 -> 长段 -> 一句短段。** 即使每个短句单独看都说得通，只要它们以固定间隔反复出现，就会显得刻意。
- 不要把“问题也正出在这里。”“开放，于是意味着散热。”“当然，这并不是……”这类承上启下句机械拆成独立段；多数情况下它们应该成为下一段首句或上一段收尾。
- 段落切换只来自场景、对象、时间、分析层次或情绪焦点的真实变化。

最终只看段落轮廓再检查一次：若单句段像标点一样等距出现，或整页呈现明显“长、短、长、短”的节拍，必须重排。

## 8. 角色主题服务感官，不替代感官

音乐、占卜、稻谷、骑士、通讯、记忆、尘埃等角色意象都可以很好地进入比喻和结尾，但必须先有足够具体的鞋袜与足部感官内容作为落点。

推荐：

`具体鞋袜状态 -> 感官变化 -> 角色主题类比`

避免：

`角色主题 -> 大段人物抒情 -> 最后只顺手提一次鞋`
## 9. 低气味角色允许“异常条件测试”，但必须有角色反应

当常态推导得到清爽、轻微甚至近乎无味时，不必永远停在这个结论。若原因只是良好透气、活动量低、清洁勤快、日常环境舒适等**可被现实条件打破的因素**，可以安排一次合理异常：

- 临时高强度作战或长时间奔走。
- 突然忙碌，连续几天没有完整整理鞋袜的时间。
- 长途外勤、驻扎或交通中断，清洗与换洗条件有限。
- 炎热、潮湿、密闭、粉尘等特殊环境。
- 连续值班、拍摄、仪仗、医疗、工程等角色职业能自然产生的高负荷日程。

必须同时满足：

1. 先建立常态基线，说明平时为什么清淡。
2. 异常条件来自角色真实工作和世界环境，而不是为了“强行变臭”随机降下灾难。
3. 只选最合适的一两个变量，不把“高温 + 几天不洗 + 连战 + 鞋坏 + 泥水”全部叠加。
4. **角色反应是正文的一部分。** 她是否烦躁、尴尬、无所谓、理性处理、立刻清洗、暂时忍耐、把它当劳动证明，都应由性格和职业决定。
5. 角色反应要进一步改变动作：换鞋、晾晒、清洗、消毒、遮掩、接受、继续任务、向同伴求助等，而不是只写一句“她很尴尬”。

若角色在设定上没有真实生理代谢、不会出汗，或当前形态本身是模拟/投影/非实体，则不要用压力场景硬造汗味。可以写材料、外界附着、模拟痕迹或“依旧没有”的反差。


## 10. v7：固定文风底座高于模式，技巧不再被“降级”

当前明确偏好更新为：

- `global-style-floor.md + prose-rhythm.md + style-metrics.md` 属于所有模式共享的不可覆盖文风底座。
- `literary / balanced / professional` 只能改变内容组织、分析深度、意象密度和同人延伸方式，不能改变短句密度、句长起伏或自然段轮廓。
- `professional` 使用“简短人物背景 -> 鞋袜/足部/气味连续深挖 -> 同人延伸”的**三阶段逻辑主干**；“三阶段”不是三段排版。
- 装备记忆、特殊状态、关系场景、现实类比、感官意义反转等技巧不再称为低优先级或降级模块。它们只要能推进当前因果链，就可以自然进入正文。
- 技巧不能被拆成“一个技巧一个段落”，也不能为了表示技巧切换而插入单句过门。
- 反复出现 `长段 -> 短单句段 -> 长段` 或 ABAB 轮廓属于硬失败；文艺模式也不得用诗歌式断行制造所谓节奏。
- `sensory_intensity` 只控制感官描写深浅，不决定句法和段落，也不等于成人恋物。

## 11. 用户选项属于后台元信息，不属于文章世界

用户为了方便可以说“专业”“极重”“成人恋物开”等，但这些词只负责控制生成策略。成文时要把它们完全消化掉，和“PRTS”“精二立绘”一样，不把后台操作暴露给读者。

硬规则：

- 不写“极重模式 / 专业模式 / 成人恋物 / 本次强度 / 本次选择 / 这个档位”等配置自述。
- 不把“极重”“成人恋物”等选择项包装成文章里的分析概念，例如“真正把情况推到极重”“这个角色的成人恋物有趣之处”。
- 只写这些选择最终造成的世界内效果：更充分的积累、更密的感官层次、更连续的材料推导、更亲密但符合角色的成人互动。
- 输出前专门做一次“配置泄漏”扫描；发现后改写为具体状态、动作、因果或关系，而不是简单删词导致句子空洞。
