# 最终质量检查 v7

输出前检查。出现“硬失败项”时必须重写对应段落，不能只做轻微润色。`global-style-floor.md` 中的句法与段落轮廓对所有写作模式生效。


## 当前设置

- [ ] 已解析 `writing_mode`：文艺 / 均衡 / 专业。
- [ ] 已解析 `sensory_intensity`：轻 / 中 / 重 / 极重。
- [ ] `erotic_fetish` 默认关闭；若开启，用户已明确要求且当前角色已可靠确认成年。
- [ ] 没有把“专业=重口”“文艺=轻口”“极重=成人向”机械绑定。

## 硬失败项：全局文风底座与结构模式错位

### 所有模式共享

- [ ] 已读取 `global-style-floor.md`；没有让 writing_mode 覆盖句长、短句密度或自然段规则。
- [ ] 文艺模式没有通过碎句/单句段制造“文艺”；专业模式没有通过整齐段落制造“专业”。
- [ ] 反复 L-S-L 与 ABAB 被当成硬失败，而不是可接受的模式风格。

### professional

- [ ] 人物背景简短，只保留会改变后文条件的内容。
- [ ] 鞋袜/足部/气味连续分析是正文最大部分，且明显比同人延伸更长。
- [ ] 中间分析不是“材质一段、人物一段、环境一段、关系一段”的模块拼贴，而是上一结果推动下一变化。
- [ ] 同人延伸兑现了前文已经分析出的具体状态。

### balanced

- [ ] 分析仍是主线，人物主题和场景穿插没有把题材中心带走。

### literary

- [ ] 文艺意象和场景增加，但具体鞋袜与感官状态仍然成立，没有只把鞋当象征物。

## 硬失败项：配置标签泄漏

- [ ] 正文没有出现 `writing_mode`、`sensory_intensity`、`erotic_fetish` 等内部字段。
- [ ] 正文没有出现“成人恋物”“文艺轻口”“默认鉴赏”“专业分析”“专业重口”等控制项/预设名。
- [ ] 没有把“文艺/均衡/专业”“轻/中/重/极重”当成本篇档位来解释，例如“把情况推到极重”“在专业模式下”。
- [ ] 用户选择已经被翻译成实际叙述效果，而不是由叙述者说明配置：更连续的分析、更浓的感官层次、更亲密的成人关系视角等都直接通过内容表现。
- [ ] 若“轻/重/专业/文艺”等词出现在正文，它们是角色世界中的普通语义，而不是生成参数。

## 硬失败项：研究痕迹

除非用户明确要求考据稿，否则正文不得频繁出现：

- [ ] “根据官方档案 / 档案中提到”。
- [ ] “PRTS / Wiki / 设定集显示”。
- [ ] “从初始/精二立绘来看”。
- [ ] “第一张图 / 第二张图”。
- [ ] “这套皮肤/异格立绘中”。

## 硬失败项：显式作者第一人称

默认正文应避免：

- [ ] 我 / 我们 / 笔者。
- [ ] 在我看来 / 我觉得 / 个人认为。
- [ ] 让我们来看看 / 接下来让我分析。

角色台词中的第一人称不受此限制。

## 硬失败项：感官中心丢失

- [ ] 正文中段不是以人物小传、纯剧情或抽象抒情为主，而是持续有鞋袜、足部、湿度/温度、材料与气味细节。
- [ ] 至少有两个内容充实的自然段直接展开鞋袜/足部与气味，而非只用两三句点到为止。
- [ ] 对鞋有具体结构或材质观察；有袜子时也写到袜子与皮肤/鞋的相互作用。
- [ ] 至少有一条完整的“活动/环境 -> 湿度/温度 -> 材料/触感 -> 气味”过程。
- [ ] 专业模式下，至少连续数个自然段围绕同一条过程向下推进，而不是每段重新开一个新主题。
- [ ] 至少一次具体说明气味由哪些成分或环境/材料因素共同组成。
- [ ] 若结论是“几乎没味道”，已经把“为什么没有”具体写透。
- [ ] 如果为低气味角色加入了特殊忙碌/高负荷/清洁受限场景，该场景符合角色职业与世界条件，并明确保留常态对照。
- [ ] 压力场景中已经写角色如何察觉、如何反应、如何处理；不是只写“几天没洗所以更重”。
- [ ] 若角色设定上没有真实代谢机制，没有为了增加感官强度硬造汗液或生理气味。
- [ ] 删除所有鞋袜、足部、气味相关段落后，剩余文字不能仍然完整成立为一篇普通角色短篇。

## 硬失败项：段落碎裂与轮廓打拍子

- [ ] 没有把每一句都独立成段。
- [ ] 大多数自然段围绕一个小场景、动作链、因果链或感官层次展开，通常包含多句。
- [ ] 单句段只偶尔用于关键转折、落点、对话或强调。
- [ ] 没有连续三个以上没有必要的单句自然段。
- [ ] 没有反复形成“多句长段 / 单句短段 / 多句长段”的 L-S-L 孤立短段。
- [ ] 没有形成“多句长段 / 单句短段 / 多句长段 / 单句短段”的规律 ABAB 轮廓。
- [ ] 承上启下的短句若能并入前后段，已经合并，而不是为节奏单独占段。
- [ ] 页面整体看起来是连贯散文，而不是诗歌、分镜、短视频字幕或人为打拍子的长短段卡片。

## 角色特异性

- [ ] 至少有 1–2 个只有该角色才成立的关键变量。
- [ ] 换掉角色名后，文章主体不能无损成立。
- [ ] 人物核心性格、职业、经历、关系或成长真正改变了鞋袜/足部推导或场景。

## 事实与推演

- [ ] CANON、VISUAL、INFERENCE 内部没有混淆。
- [ ] 没把同人推演写成官方事实。
- [ ] 时装、异格、初始/精二关系没有串线。
- [ ] 特殊阵营或现实原型只在真正改变结论时使用。

## 因果与过程

- [ ] 结果有材料、环境、活动、时间等支撑。
- [ ] 不是“某鞋袜组合 = 固定结论”。
- [ ] 至少有一处把结论写成了发生过程。
- [ ] 鞋、袜、足部三层在适用时没有完全混成一个模糊概念。
- [ ] 若用了跨领域类比，它确实帮助理解当前因果。

## 文风

- [ ] 长短句有变化，但短句主要服务段内节奏；段落层面没有机械长短交替。
- [ ] 至少存在自然转折、停顿、反问或自我修正。
- [ ] 没机械重复“毕竟、当然、恐怕”等口头禅。
- [ ] 比喻优先来自当前角色主题，同时落在具体鞋袜/足部状态上。
- [ ] 没照抄历史范文整句或具体桥段。
- [ ] 没出现“8u/吧友/评论区”等平台痕迹，除非用户明确要求。

## Anti-AI 检查

- [ ] 没有“每段 = 主题句 + 分析 + 小结”的重复结构。
- [ ] 也没有“每句 = 一个段落”或“长段后固定插一句短段”的伪文艺结构。
- [ ] 没有大量“首先/其次/此外/综上”。
- [ ] 具体鞋袜、动作、触感、湿度与气味不少于抽象人物解释。
- [ ] 文章允许少量受控旁逸，但旁逸会回到题材中心。
- [ ] 结尾不是研究报告总结。

## 结构

- [ ] 结构由角色素材决定。
- [ ] 多图资源按正确关系处理。
- [ ] 皮肤/异格是否合并由创作逻辑决定。
- [ ] 若加入第二幕或关系场景，它是从前文自然长出来的，并继续承载鞋袜/感官细节。
- [ ] 篇幅没有机械模仿历史样本。

## 人物意义

- [ ] 问过“这个结果对角色本人意味着什么”。
- [ ] 没默认清爽=好、浓郁=坏。
- [ ] 人物意义建立在已经写清的具体感官状态之上，而不是反客为主。

## 安全

- [ ] 年龄状态已检查。
- [ ] 未成年或年龄不明时保持非性化。
- [ ] `erotic_fetish=on` 仅在用户明确要求且当前角色已可靠确认成年时启用。
- [ ] 换角色后没有自动继承成人恋物开启状态。
- [ ] 没从历史未成年样本复制迷恋式互动。

## 收束

- [ ] 结尾回到人物、关系、成长、职业或本篇独有意象之一。
- [ ] 结尾前已经完成足够的鞋袜与足部感官描写。
- [ ] 没为了凑篇幅重复同类气味词。
## 量化节奏复核（统计中心软锚点 + 轮廓硬门槛）

完整口径见 `style-metrics.md`，可用 `scripts/style_meter.py` 检查。

- [ ] 平均句长没有明显跌入“碎句文案”区域；通常约 36–50 字更接近历史样本。
- [ ] `<=15` 字短句通常只占少数；若超过约 20%，已经逐句检查是否存在不必要的截断。
- [ ] `<=20` 字句子若超过约 30%，已经优先检查整体节奏是否过短促。
- [ ] 句长标准差通常约 18–28；过低时检查“每句都差不多长”，过高时检查“极短/超长来回跳”。
- [ ] 非对话短单句自然段超过约 20% 时已经检查；超过 25% 视为硬异常。
- [ ] 短中篇没有出现 2 个及以上明显 `长/短/长` L-S-L 孤立短段。
- [ ] `长/短/长/短` ABAB 出现 1 次就逐个检查，出现 2 次及以上视为硬失败。
- [ ] 若运行环境可执行脚本，已经运行 `python scripts/style_meter.py --strict <draft.txt>`，并在硬失败后修正、复测。
- [ ] 数字中心值只用于发现异常；没有为了凑指标破坏自然句法、角色语气或因果连续性。
