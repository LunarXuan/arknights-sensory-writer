# 鞋袜、足部与气味推导框架 v7

## 总公式

`Person × Form/Timeline × Outfit × Occupation × Environment × Activity × Material × Time × Equipment history -> Sensory state -> Character meaning`

角色意义是最后一层，不是替代前面的感官过程。先把鞋袜与足部具体写清，再谈人物主题。

## Sensory map / 写作前感官地图

在动笔前内部快速列出：

- `shoe`：鞋型、鞋口、鞋底、鞋垫、内衬、材质可能性、开放/封闭程度、固定方式、磨损与旧痕。
- `sock`：是否穿袜；袜类、长度、厚薄、吸湿、贴合、摩擦、清洗与残留。没有袜子时跳过。
- `foot`：温度、干湿、压迫、摩擦、黏腻、放松、粗糙/柔软、局部接触差异。
- `odor`：主要来源、材料混味、浓淡、扩散方式、脱鞋前后变化、放置/清洗后的变化。
- `time`：穿了多久、活动多久、是否重复穿着、装备是否已有历史。

正文不需要把这五项按表格逐一汇报，但至少要让其中三到四项真正进入文章。不能只有角色故事和一句“鞋里有些闷”。

## 题材中心的最低完成度

一般完整鉴赏至少应满足以下几件事：

1. 对鞋本身有具体观察，不只写“靴子/高跟鞋/运动鞋”名称。
2. 若有袜子或裤袜，说明它与鞋、皮肤之间如何相互作用。
3. 至少写清一条从活动/环境到湿度、温度、材料状态再到气味的过程。
4. 至少一次具体写气味由什么组成，而不是只说“有味道/有异味”。
5. 至少一次说明脱下、放置、清洗、再次穿着或时间推移后状态如何变化。

这不是固定五段模板，可以合并、打散或省略不适用项；它的作用是防止文章滑成普通人物同人短篇。

## 气味组成不要一笔带过

气味可以来自多层：

- 汗液本身的咸湿、潮气。
- 长时间闷热后出现的酸腻、发酵感。
- 皮革、橡胶、塑料、织物、毛绒、金属处理等材料气味。
- 香水、洗衣液、消毒剂、防晒霜等生活用品残留。
- 泥土、草木、海水、矿物、粉尘、工作环境等外部气息。
- 旧鞋、鞋垫、重复穿着形成的长期残留。

不要每篇都堆满所有词。优先选与角色、装备和环境真正有关的 2–4 层，并写出它们为什么会同时存在、谁更突出、何时变化。

## 多因素推理

优先写相互制约，而不是单线结论：

- 鞋很透气，但袜子厚。
- 袜子轻薄，但鞋内衬吸水。
- 环境寒冷，但活动量高。
- 活动量小，但长期不清洗。
- 装备为了防护而封闭，牺牲透气。
- 开放式鞋整体通风，但足底接触区仍然局部闷热。

允许先得出直觉结论，再由角色专属条件推翻或修正。

## Process first / 过程优先

能写成过程，就不要只写结论。

差：

> 穿久以后会很潮湿，脚上也有些味道。

更好：

`汗液出现 -> 织物吸收/不吸收 -> 向下移动 -> 鞋垫变软 -> 足底接触变化 -> 脱下后热气和气味释放 -> 放置后水汽减弱但材料与酸味更清楚`

过程可以包含：

- 流动。
- 蒸发。
- 冷凝。
- 吸附。
- 摩擦。
- 干燥。
- 残留。
- 清洗。
- 再次穿着。

## 鞋、袜、足部三层可以互相不同

如果文章篇幅和装备结构允许，可以区分：

- 鞋内：更多材料味、旧残留、鞋垫积累和整体闷气。
- 袜子：更贴近皮肤，容易保留汗液、织物、清洗剂和局部湿痕。
- 足部：更偏当前一次穿着形成的温度、湿度、代谢与局部接触结果。

不要求每篇都逐层扫描，但不能把三者完全混成一个模糊的“脚臭”。

## 功能—代价推导

先找功能，再找代价：

- 防护更强 -> 可能牺牲透气/轻便。
- 保温更强 -> 活动后热量更难散出。
- 防水 -> 外部水进不去，内部汗也难出去。
- 贴合更好 -> 摩擦和局部密闭增加。
- 开放式凉鞋 -> 整体通风，但足底仍持续接触鞋垫。

## 原生环境反差

`原生环境适配 -> 离开原生环境 -> 条件变化 -> 原本优点出现新代价`

适用于海洋、雪地、荒野、矿井、炎热地区等。

## 环境可以进入气味，但不能把足部挤没

矿井、泥土、地下水、粉尘、海水、火山泉、草木、消毒剂、舞台设备等都可以成为重要气味来源。

但最终仍要回答：这些东西如何附着在鞋、袜、足部上？如何和汗液、材料、清洗状态混在一起？如果只写环境氛围而没有回到身体和装备，就还没完成题材任务。

## Equipment memory / 装备记忆

三类主要来源：

1. 材质限制：难清洗、难晾晒、吸附。
2. 使用习惯：重复穿着、延迟清洗、随手收纳。
3. 恶劣环境污染：泥水、矿物质、粉尘等长期残留。

形成循环：

`身体影响装备 -> 装备积累 -> 下次穿着 -> 装备反过来影响身体`

装备记忆尤其适合增加鞋袜描写密度，因为它能把“一次任务”扩展成“长期使用历史”。

## Odor / sensory timeline / 时间变化

允许状态随时间变化：

- 穿着早期：材料本身、轻微温热或汗意。
- 穿着中段：局部潮湿、织物贴合、鞋垫触感变化。
- 刚脱下：热气、水汽、整体闷味最先释放。
- 放置片刻：水汽减弱，酸味、材料味、织物味更容易区分。
- 蒸发后：盐分、残留和干涩感突出。
- 长期存放：某些痕迹被浓缩或由装备历史主导。
- 清洗后：主体状态消退，但材料、香氛或旧装备可能留下另一层。

## “没有气味”先建立基线，再判断是否需要压力测试

某些角色或设定可能导致极低气味，甚至没有真实生理过程。此时不要把文章完全转成人物哲思。

仍然可以写：

- 鞋内是否升温。
- 是否存在汗液、潮气或织物吸湿。
- 鞋垫是否因体重和行走发生形变。
- 是否有材料本身的气息。
- 是否有穿着后的旧鞋贴合感。
- 脱下时是否存在热气释放或完全没有。
- 与真实角色穿过一天的鞋形成什么具体对照。

“缺失”本身也需要一整套感官证据。

接着判断这个低气味结论属于哪一种：

- **稳定不可破坏型**：非实体、模拟身体、明确无真实代谢等。保持无味，不硬造汗液。
- **常态条件型**：透气好、活动少、清洁勤、天气凉、穿着时间短。可以在需要更多展开时安排一次合理压力场景，看这些保护条件失效后会怎样。

压力场景不是默认必选项，也不是“想办法把每个人写臭”。它只是在常态太清淡时提供新的真实变量。详细规则见 `exception-scenarios.md`。

## Reaction coupling / 状态必须和角色反应耦合

无论是常态还是异常状态，角色本人都不是被动容器。写完“发生了什么”后继续问：

- 她什么时候注意到？是触觉、气味、鞋袜状态，还是旁人提醒？
- 她第一反应是什么？烦躁、羞窘、理性、无所谓、好奇、接受？
- 她会不会因为职业知识或生活习惯采取不同处理方式？
- 反应是否改变了后续动作和装备状态？

尤其在为低气味角色加入高负荷/缺少清洁条件时，必须把这条链写出来：

`异常条件 -> 感官变化 -> 角色察觉 -> 性格化反应 -> 处理/忍耐 -> 新的鞋袜状态`

只写“几天没洗所以味道变重”而不写角色如何面对，视为不完整。

## Sensory meaning inversion / 感官意义反转

不要给状态预设价值。同一状态可以意味着尴尬、温暖、安全、劳动证明、训练成果或对过去的接纳。

执行顺序必须是：

`先写具体状态 -> 再问它对角色意味着什么`

不要一开始就追着抽象主题跑。

## Cross-domain analogy / 跨领域类比

可以把一个物理过程类比成现实世界另一现象，例如蒸发与矿物质残留、发酵与食物/酒类、扩香与调香、冷凝水、泥土吸附、织物储存。

要求：类比必须帮助理解当前鞋袜/足部过程，并与角色主题或场景相容。

## 局部差异

只有长篇或真的存在结构差异时才区分：

- 足弓、足底、趾部、趾缝、足跟。
- 鞋内、鞋垫、袜子、足部本身。

不要把逐区扫描做成固定模板；但如果文章已经很长却完全没有任何具体接触区域，也可能说明描写过于抽象。

## 角色处理闭环

继续问：“角色本人会怎么处理？”

`问题形成 -> 角色发现 -> 按性格/职业处理 -> 是否有效 -> 装备留下什么 -> 回到人物生活`

处理方式可以是清洗、晾晒、换鞋、消毒、工程维护、忽略、接受、开玩笑等。

## 生理细节谨慎

使用常识性、非诊断性的描述支持文学推演。不要把“微生物、体温、代谢”等写成确定定量医学结论。
