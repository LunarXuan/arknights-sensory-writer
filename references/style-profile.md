# 文风画像 v7

## 1. 先学“思路怎么往下走”，再学词汇

最稳定的特征不是某几个口头禅，而是：

- 先从角色身份、气质或一件具体视觉细节切入。
- 很快落到鞋袜、足部和穿着条件，不让人物介绍无限延长。
- 给出一个直觉判断，再用角色专属变量修正它。
- 把“会怎样”写成过程：动作、等待、升温、潮湿、摩擦、积累、脱鞋、散发、清洗、放置、再次穿着。
- 让人物设定真正改变结果，而不是作为百科前言。
- 让场景自然长出来，但场景里仍然持续存在鞋袜与足部状态。
- 最后经常回到人物本人、成长、职业、关系或一个主题意象。

## 2. 题材主次

人物设定与剧情是骨架，鞋袜、足部状态与气味是肉。

优先：

`人物切口 -> 鞋袜细节 -> 动作/环境 -> 湿度与触感变化 -> 气味层次 -> 场景继续 -> 人物意义`

避免：

`人物背景 -> 大段剧情 -> 抽象主题 -> 结尾顺手提一句鞋`

如果一篇文章读起来首先像“角色文学短篇”，其次才像“足部气味鉴赏”，通常说明主次反了。

## 3. 当前成文目标

正文应该像作者已经熟悉这个人，于是自然知道她穿什么、怎么活动、鞋袜会发生什么、自己会如何处理这些变化，而不是模型站在世界外做资料说明。

研究过程只存在于后台。

## 4. 隐形叙述者

叙述者可以明显有态度，但默认不显式说“我”。

推荐气质：

- 一本正经分析略带荒诞的事情。
- 认真推导中偶尔突然轻佻或戏谑一下。
- 不害怕反问、停顿、重复和自我修正。
- 对角色可以有温柔、怜惜、惊讶、好奇，但不需要声明“作者觉得”。

## 5. 自然段，而不是一句一段

当前写法明确避免对独立短句段和人为“长短对比”的过度鼓励。

更接近当前目标的段落习惯是：

- 一个自然段围绕同一小场景、动作链、因果链或感官层次。
- 段内可以同时存在长句和短句。
- 不固定自然段句数，以语义完整为准。
- 单句段很少，只在真正需要强调、反转、停顿或对话时使用。
- 不连续铺满“短句。换段。短句。换段。”，也不采用“长段 -> 单句短段 -> 长段 -> 单句短段”的规律排版。
- 转折短句如果只是连接前后内容，通常并入相邻段，而不是独立占一段。

短句是一种句法节奏，不是一种默认排版格式；段落长度也不应该承担人为打拍子的任务。

## 6. 感官描写需要足够密度

“气味鉴赏”不只是偶尔写到“有些汗味”。文章通常需要具体处理：

- 鞋的结构、材料、鞋垫/内衬和旧痕。
- 袜子或裤袜如何贴着肌肤、吸收或留不住水分。
- 足部的温度、潮湿、黏腻、摩擦、压迫、放松等状态。
- 气味由汗液、材料、环境、清洗剂、旧鞋残留等哪些层次组成。
- 刚脱下、放一会儿、清洗后、再次穿着时如何变化。

不要求每篇把这些逐项列完，但正文中段要让读者一直能感到“鞋袜和足部仍然在场”。

## 7. 角色主题进入比喻系统，但不能反客为主

先提取人物专属意象，再用它们决定比喻和结尾：音乐、占卜、耕作、骑士、荒野、机械、通讯、记忆等都可以成为语言来源。

正确顺序：

`具体感官 -> 人物主题类比`

例如先有材料、汗液、时间层次，再用乐章、发酵、磨损、尘埃等主题去解释。

不要只因为某个主题很漂亮，就连续数段抒情而忘记鞋袜和气味。

## 8. 清淡角色也允许被特殊条件改变

如果常态推导确实很清爽，不需要硬改结论；但当清爽来自透气、活动少、清洁勤等可变条件时，可以让一次合理的忙碌、连续外勤、高强度任务或清洁受限打破平衡。重点必须落在“变化过程 + 角色反应”，而不是只为了让数值变重。

## 9. 感官结果本身也有“人物意义”

不要默认清爽就是好、浓郁就是坏。同一种状态可能意味着：尴尬、劳动成果、训练证明、温暖、安全、成长、对过去的接纳，或某种只有熟人才会注意到的私人状态。

但必须先把“状态是什么”写具体，再问“这对她意味着什么”。

## 10. 允许受控旁逸

主线建立后，可以因为一个物件、兴趣、关系、时装或现实类比暂时拐出去。

旁支必须满足至少一项：

- 更像这个角色。
- 让前文鞋袜/足部状态进入具体场景。
- 提供新的感官条件或对照。
- 让结尾有东西可以回扣。

若旁支连续多段都与鞋袜、足部、气味无关，应主动收回来。

## 11. author_affinity

只在用户明确说喜欢某角色时启用：

- `neutral`：正常观察。
- `liked`：更关注小动作、成长、生活状态，结尾更温柔。
- `strongly_liked`：允许明显偏爱，但仍不牺牲角色真实性和因果逻辑。

不要写“我最喜欢她”。偏爱应该体现在观察角度上。

## 12. 明确不要学习

- “8u / 吧友 / 评论区”等平台痕迹。
- 把历史文章里的第一人称当当前目标。
- “从立绘中可以看出 / 在档案中 / 设定集说明”等来源暴露。
- 因为某篇短就学习成短篇偏好。
- 固定复用某个博士互动或具体荒诞桥段。
- 把历史样本的同人推演当成 CANON。
- 每篇都逐区扫描鞋、袜、足弓、趾缝、鞋垫。
- 把“人物主题回扣”误学成大段纯人物抒情。
- 把“短句有节奏”误学成一句一段，或机械的长段/单句段交替。

## 13. 最终感觉

理想输出应该让人觉得：这首先是一篇鞋袜、足部气味与感官鉴赏，其次才借人物设定让它变成只有这个角色才能成立的文章。角色不是被资料介绍出来的，而是在鞋、袜、动作、气味、清洗和生活细节里慢慢显出来。
## 14. 量化风格锚点

历史语料进一步验证：作者并不是“高短句密度”文风。38 篇样本合并后，平均句长约 43.3 字、中位 38、标准差约 24.2；`<=15` 字句只约 7.8%，而 `>=45` 字句约 40.6%。因此真正应学习的是**中长句占主体 + 少量短句落点 + 较高句长方差**，而不是一段一短句的伪节奏。

详细定义、分位数、段落反模式阈值见 `style-metrics.md`。这些数字是校准工具，不取代自然语言判断。


## 15. v7：把“怎么写”和“写到多重”分开，但共享固定文风底座

当前 Skill 允许三个内容组织面向，但它们共享同一套句法和自然段文风：

- 文艺：人物意象和生活感更强，分析更含蓄。
- 均衡：默认，分析与人物主题互相穿插。
- 专业：最接近作者大量传统鉴赏文的主干——简短背景后，把鞋袜、足部和气味连续写深，最后再自然长出同人内容。

另用“轻/中/重/极重”控制感官密度。不要把“文艺=轻口”或“专业=重口”绑定；用户可以要求“文艺重口”或“专业轻口”。成人恋物又是第三个独立开关。

## 16. 专业模式下的连续性

专业模式最常见失败不是内容不足，而是内容零散。避免：

`材质一段 -> 人物背景一段 -> 气味一段 -> 关系一段 -> 装备记忆一段`

优先：

`鞋为什么这样设计 -> 角色怎样活动 -> 哪些位置先变化 -> 水汽/汗液怎样进入袜子与鞋垫 -> 材料怎样储存或散失 -> 气味怎样出现 -> 脱下后怎样变化 -> 角色怎样处理 -> 这个结果怎样自然进入同人场景`

让上一段的结果成为下一段的条件，文章就会像一条不断加深的推导，而不是卡片拼贴。


## 17. 固定文风底座与模式的关系

所有模式都保持：中长句为主体、短句低密度、句长方差明显、自然段由语义单元决定。文艺模式不能通过更多单句段体现“文艺”，专业模式也不能通过整齐段落体现“专业”。

当模式要求与段落轮廓发生冲突时，以 `global-style-floor.md` 为准。特别是 `L-S-L`、`L-S-L-S` 和近似固定间隔的短单句段，要在输出前主动重排。
