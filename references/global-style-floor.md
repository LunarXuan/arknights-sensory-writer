# 全局不可覆盖文风底座 v7

## 目的

本文件定义所有写作模式共同服从的固定文风底座。`literary / balanced / professional` 只能改变内容权重、分析深度、意象密度和同人延伸方式，**不得改变基础句法、短句密度、自然段轮廓和研究痕迹规则**。

优先级固定为：

`安全与年龄边界 -> 当前风格硬约束 -> 本文件的句法/段落底座 -> 用户本次三个旋钮 -> 内容组织与创作技巧`

任何模式、预设、主题意象、同人场景或“为了节奏”产生的写法，都不能覆盖前三级。

## 一、固定句法底座

无论哪种 `writing_mode`，都保持以下共同特征：

- 中长句是正文主体，允许连续因果链、动作链和感官过程在一个复句中展开。
- 极短句只少量出现，用于真正的落点、反转、迟疑、对话或强调。
- 短句首先服务**段内节奏**，不是换段信号。
- 句长要有明显但不机械的起伏；不要统一修成长句，也不要为了“文艺”大量拆成碎句。
- 反问、省略号、破折号、重复和自我修正可以使用，但必须推进意义。

量化锚点见 `style-metrics.md`。其中统计值本身是软区间，但以下反模式属于全局硬失败：

- `<=15` 字短句明显泛滥，并与大量单句段同时出现。
- 连续或反复出现“长段 -> 短单句段 -> 长段”的孤立短段节拍。
- 出现规律性的“长段 -> 短单句段 -> 长段 -> 短单句段”ABAB 轮廓。
- 为了制造视觉节奏而把本可连在一起的判断句、转折句、补充句单独成段。

## 二、固定自然段底座

自然段由**语义单元**决定，不由句长决定。

一个自然段通常围绕以下之一持续展开多句：

- 一个小场景。
- 一条动作链。
- 一条因果链。
- 一个连续感官层次。
- 一个明确对象，如鞋、袜、足部或清洗过程。

优先换段的理由：

- 场景或时间真正改变。
- 分析对象明显改变，并且新的对象需要单独展开。
- 人物态度发生明显反转。
- 对话成为独立动作单元。
- 前一条因果链已经完成，新一条链开始。

**不构成换段理由**：

- “不过”“当然”“那么”“问题也正出在这里”之类普通转折。
- 单纯想让页面“有节奏”。
- 上一段太长，想用一句短段做视觉缓冲。
- 刚写完一个长句，想故意放一个短句。

## 三、段落轮廓硬门槛

草稿完成后必须做一次“只看轮廓、不看内容”的复核。

把自然段粗略标记为：

- `S`：单句且较短，通常 <= 30 个有效字符。
- `L`：明显较长且包含多句或连续展开。
- `M`：其他正常自然段。

检查：

1. `L-S-L`：若一个短单句段夹在两个长段之间，先默认它应并入前后段，除非它确实承担独立场景、独立对话或真正反转。
2. `L-S-L-S` / `S-L-S-L`：任何一次都需要人工检查；短中篇出现 2 次及以上视为硬失败。
3. 若非对话短单句段以近似固定间隔重复出现，视为硬失败，即使没有形成完整 ABAB。
4. 若把单句段的换行删掉后全文更自然，必须合并。

不要为了“随机化”刻意把段落长短打乱；只需让语义决定换段，视觉轮廓自然会不规则。

## 四、三个旋钮不得改写文风底座

### literary

可以：

- 增加意象、生活感、人物主题和情绪回扣。
- 让分析更含蓄，减少术语感。
- 提前让同人场景与分析交织。

不可以：

- 因为“文艺”就增加大量极短句、单句段、诗歌式断行。
- 把长段+单句段交替误当成文艺节奏。

### balanced

在同一固定句法和段落底座上平衡分析与人物主题，不拥有独立排版风格。

### professional

可以：

- 提高连续分析占比。
- 延长同一因果链的深挖。
- 更明确区分鞋、袜、足部、材料、时间与气味。

不可以：

- 把“专业”写成报告段落。
- 用固定三段排版表现“三阶段逻辑”。
- 在每一阶段之间插一个单句转折段。

## 五、三阶段是逻辑，不是排版

专业模式中的：

`简短人物背景 -> 鞋袜/足部/气味连续深挖 -> 同人延伸`

称为**三阶段逻辑主干**，不是“三段式”。

- 第一阶段可以占 1–2 个自然段。
- 第二阶段通常跨越多个自然段，是正文主体。
- 第三阶段也可以与第二阶段自然重叠，而不是必须另起一个醒目的“尾声段”。
- 阶段切换不要求单独转折句，更不要求固定换段。

## 六、生成后强制复核

如果运行环境能执行脚本，完整草稿后必须运行：

```bash
python scripts/style_meter.py --strict <draft.txt>
```

若返回硬失败：

1. 先只修句法和分段，不改人物事实和核心分析逻辑。
2. 把无必要的短单句段并入前后语义单元。
3. 检查极短句是否真有强调作用。
4. 再运行一次 `--strict`。
5. 仍失败时继续修正，不能把警报当作“仅供参考”。

若脚本不可用，则按本文件和 `quality-checklist.md` 手工执行同样的轮廓检查。

量化指标用于发现漂移，不要求机械凑到某个均值；但**反复 L-S-L、ABAB、短单句泛滥属于硬失败，不是软偏差**。
