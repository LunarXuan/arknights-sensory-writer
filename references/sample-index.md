# 历史样本索引 v7

## 总规则

- 样本顺序按作者提供顺序/姓名习惯出现，不代表质量权重。
- 不给整篇文章单一“高/低权重”；分别学习思路、结构、句法、转场和历史噪声。
- 当前明确风格偏好高于旧文中的历史习惯。
- 未成年样本只保留非性化结构、节奏和人物融合方法。
- 写新文时优先选 2–4 个“结构近邻”，不要加载所有样本后平均模仿。
- v3 新增：近邻样本中至少选择 1 个鞋袜/足部感官密度高的段落，避免只学人物主题和抒情收束。
- v3 新增：历史样本里的单句段只能作为少量强调手段，不能推导出“一句一段”的默认排版。
- 当前规则：历史样本的换行位置不作为排版模板；尤其禁止把“长段 + 一句短段”规律交替当成作者固定节奏。
- 当前规则：低气味角色先保留常态基线；若清爽来自可变条件，可用一次合理压力场景扩展，但必须同步学习角色如何察觉、反应与处理。

## 高价值结构与节奏样本

### 塑心 / 阿尔图罗

学习：人物设定引入；等待比战斗更重要；音乐主题贯穿比喻；分层推进；结尾回到人物和乐章。

当前修正：历史原文里偶有引文/研究式开头，生成时不必展示来源。

### 阿斯卡纶

学习：设定与感官交织；环境变化带来动态结果；潜伏、痕迹、记忆进入比喻系统；感性收束。

避免：把“气味作为任务工具”等同人推演误当 CANON。

### 死芒 / 爱布拉娜

学习：角色核心矛盾驱动；生/死、优雅/危险、冷/热进入全文骨架；结尾把结果映射到人物。

### 锏

学习：人物气质先决定视觉解读；功能与代价；脱下后的时间变化；局部层次可选；装备残留类比人物过往。

高价值结尾模式：从物理痕迹突然回到一个人的过去，不做报告式总结。

### 琴柳

学习：人物气质开篇；“优雅”被“坚毅”修正；仪仗装备功能代价；训练与下午茶形成反差；环境可以把感官状态从汗湿转向泥土、草地和放松。

高权重：整体节奏、人物气质到场景的自然滑动。

### 深巡

学习：防水布料 -> 蒸发/凝结 -> 液体下移 -> 紧靴的连续物理过程；装备故障直接变成事件；“解除封印”式夸张比喻；过去到现在的熟练变化。

当前修正：历史原文中“档案中……”属于要过滤的元叙述。

### 史尔特尔

学习：火焰/高温与服装条件叠加；现实物理现象类比；把“难清洗”写成连续步骤；联动拍摄可自然成为第二幕。

当前修正：历史原文“立绘中”等说法生成时隐藏。

### 守林人

学习：感官意义反转。对别人是不舒服的状态，对长期寒冷荒野中的她可能意味着温暖、安全、身体仍然正常。

高权重：问“这件事对角色本人意味着什么”。

### 早露

学习：过去极端生存经历与当前日常形成心理对照；重点不是强弱，而是她如何重新理解同一种身体状态；同伴接纳可以成为收束。

安全：样本文本明确强调仍在发育，执行时按年龄核验并只学习非性化结构。

### 薇薇安娜

学习：优雅和自我维护进入日常；竞技与长期外勤形成条件差异；长句后突然短句；结尾把多个阶段收束到金盏花和人物身份。

当前修正：历史“让我们来分析”不作为当前第一人称风格。

### 羽毛笔

学习：等待场景；重复词语形成节奏；汗液向下、鞋垫吸收、蒸发冷凝等过程写法；“发现层次”而不是直接给结论。

安全：执行时重新确认年龄；若无法确认成年，仅使用非性化模式。

### 夜刀

学习：存在感低、认真、平静等人物气质进入感官态度；关系场景优先使用黑角而非固定博士；结尾可以停在两个人微妙的猜测中。

### 远山

学习：占卜主题进入气味变化和“解读”比喻；长筒靴的装备记忆；夏装自然成为第二阶段。

## 角色研究与结构扩展样本

### 艾雅法拉（早期）

学习：先给直觉结论，再用身份、工作、日常修正；从作战服延伸日常；装备历史循环。

排除：8u/吧友互动；历史短篇或平台口吻不作为当前风格目标。

### 安洁莉娜时装

学习：同一人物不同 Skin 控制变量比较；人物阶段 -> 服装变化 -> 功能变化；海滩场景从背景物件读取。

### 纯烬艾雅法拉

学习：异格是同一人物的新阶段；成长后再进入当前环境；火山/水汽/矿物质成为场景专属变量。

### 嵯峨

学习：东国文化、佩洛原型、木屐/足袋与僧侣身份联动；分析后进入角色兴趣场景。

避免：复制具体“足袋发面”桥段。

### 涤火杰西卡

学习：异格“变了什么/什么没变”；作者偏爱通过观察成长体现；过去荒野经历可以进入现在。

### 豆苗

学习：职业环境可成为主要感官来源；基础主体 + 某套皮肤作为灵感尾声；工作状态与节庆状态反差。

### 歌蕾蒂娅

学习：特殊阵营二次研究；原生海洋环境与陆地环境形成装备适配反差；非战斗特色场景。

注意：特殊身体设定每次重新核实。

### 极光

学习：地区/体质解释看似矛盾的服装；功能优点制造副作用；装备难清理形成长期历史；任务后处理闭环。

### 莱伊

学习：过去职业已经结束，但行为惯性延续；矿井长期污染；视觉小细节关系化；看书兴趣自然生成日常场景。

### 妮芙

学习：开放式高跟鞋仍有局部接触区；足底/足尖局部差异；时间积累；旧鞋残留反向影响身体。

### 克洛丝 / 寒芒克洛丝

学习：三星基础形态无精二；原版 + 节庆时装 + 异格可时间轴合卷；皮肤是短暂异常状态；成长表现为程度变化。

### 空

学习：偶像公开形象与幕后状态反差；职业训练与演出；粉丝、媒体、同台演员等社会视角。

重要：历史篇幅短只是当时缺灵感，不能学习成“素材少就快速收束”。

### 黍

学习：耕作、稻谷、发酵、酒等角色主题可以贯穿比喻和场景；角色主题“污染”整套感官语言。

当前修正：历史“让我们来看看”和显式第一人称不作为当前目标。

### 水灯心

学习：游牧、运动、凉鞋、晒痕、饮食和族群生活可以共同构成角色特异性；开放鞋并不等于没有装备记忆。

注意：饮食 -> 体味等判断保持推演语气，不写成科学定论。

### 斯卡蒂 / 浊心斯卡蒂

学习：特殊阵营、海洋原生环境、装备需求与人物命运可以进入同一篇；形态变化可改变文章主题。

必须核实：浊心斯卡蒂的叙事地位与时间关系，不要机械当成普通“成长异格”。

当前修正：历史“从立绘可以看出”“我们几乎可以说”等元叙述不复现。

### 温蒂

学习：人物洁癖可彻底改变“什么程度算严重”；极轻微状态对她本人也可能意义巨大。角色主观阈值是重要变量。

### 锡兰

学习：大小姐身份与野外考察反差；礼服功能改良；黑作为最自然关系对象；红茶/香氛等生活主题可进入比喻。

当前修正：历史“从立绘中”“设定集可知”必须在生成时消化掉。

### 小满

学习：节气含义作为人物开篇意象；耕作、水靴、劳动；“不过，她其实十分开心。毕竟这是劳动的证明。”式短句价值反转；场景可以自然滑向竹笛与牧兽。

安全：执行时重新确认年龄；不从历史身体互动段落学习性化内容。

### 星极

学习：日常低强度状态与舞台演出特例；香水、织物、环境气息可以成为“扩香木”式主题；角色热爱星空可让舞台成为第二幕。

### 亚叶

学习：医疗干员的洁净、消毒、维护习惯可以直接决定处理闭环；工作与打猎两种身份形成条件对照；角色职业口吻可进入对话。

### 宴

学习：时尚身份与多套衣装推动多幕结构；允许“接下来去哪了”式受控旁逸；物件可引出食物/饮料类比。

当前修正：生成时减少读者喊话和显式“品鉴者”自我出现。

## 仅保留非性化结构的明确未成年样本

### 红

学习：SWEEP 任务优先；极端环境污染；任务 -> 返回罗德岛 -> 清洁恢复。

排除：针对年纪尚小角色的迷恋式互动。

### 玫兰莎

学习：“如果只是黑丝+靴子就泯然众人，必须找角色差别”的元原则；家庭背景和香料资源可产生生活化推演；三星无精二。

排除：成长阶段/小孩子角色的迷恋式互动。

### 泡普卡

学习：普通状态与失控状态切换；同一装备因人物状态不同而变化；恢复后的残留痕迹可成为记忆线索；三星无精二。

排除：未成年角色的迷恋式身体描写。

### 跃跃

学习：服装定语累积形成句法节奏；不对称设计与活泼性格对应；长期重复穿着形成时间层次；左右不对称袜长可以产生局部差异。

排除：样本明确称为孩子，任何恋物化或性化描写不得作为生成范例。
