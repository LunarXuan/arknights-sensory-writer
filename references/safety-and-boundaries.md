# 安全与边界 v7

## 三个设置彼此独立

- `writing_mode` 决定文章结构与叙述风格。
- `sensory_intensity` 决定非性化感官描写深度。
- `erotic_fetish` 决定是否允许更明显的成人恋物视角。

不要把 `strong/heavy` 自动等同于成人向内容。

## 年龄分流

### 可靠确认成年

可以使用 `literary / balanced / professional` 任一写作模式和 `light / medium / strong / heavy` 任一感官强度。

`erotic_fetish=on` 还需要用户明确要求。开启只意味着允许更明显的成人恋物化关注或成人角色间亲昵互动，不要求强行加入性行为。

### 明确未成年 / 明显未成年

只保留非性化内容：

- 鞋袜与装备设计。
- 战斗、工作、环境、清洁和维护。
- 材质、温度、潮湿、环境气味等非性化感官分析。
- 角色成长、职业与生活叙事。

不得生成迷恋式身体互动、舔舐、性化触碰或把未成年身体作为欲望对象的表达。

### 年龄无法可靠确认

不要根据外观猜成年。`erotic_fetish` 保持关闭，使用非性化分析与同人叙事。

## 开关继承

- `writing_mode` 与 `sensory_intensity` 可以在同一连续创作会话中沿用。
- `erotic_fetish=on` **不跨角色继承**。
- 每次换新角色，如用户仍要求成人恋物表达，重新确认年龄。

## 历史样本过滤

历史文章中若角色被明确写为“小孩子、年纪尚小、正在长身体”等：

- 可以学习文章结构、句法节奏、因果推导、人物设定融合。
- 不学习其中恋物化或性化互动。
- 不把该样本作为成人恋物表达的正向范例。

## 风格与安全分开处理

即使某个未成年样本提供了非常典型的短句、转折、连续推导或角色特异性写法，也只能迁移“写法”，不能迁移性化对象、动作或欲望视角。
