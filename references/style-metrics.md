# 量化文风参数 v7

## 目的与优先级

这些数字用于纠正“明明读过范文，却仍写成模型自己的节奏”的问题。它们与 `prose-rhythm.md` 一起构成**所有写作模式共同服从的文风底座**。

- 统计中心值是软锚点，不要求逐句凑数。
- 反复 `L-S-L`、ABAB、短单句段泛滥是硬反模式，不能被 `literary / balanced / professional` 覆盖。
- 模式只改变内容权重与分析深度，不改变这组基础节奏参数。

## 统计口径

语料来自 38 篇用户提供的历史正文样本，排除后续由模型生成、用于回归测试的 PDF。合计 686 个自然段、1303 个句子、56374 个有效字符。

- 句界：以 `。！？!?` 为主要终止符。
- 有效句长：只计汉字、字母、数字，不计标点、空格和引号。
- 省略号与破折号视为句内节奏，不自动切句。
- 这些值混合了不同时期作品；当前明确偏好（自然分段、隐藏研究来源、避免作者第一人称）优先级更高。

## 句长画像

全语料合并统计：

- 平均句长：**43.3** 个有效字符。
- 中位句长：**38**。
- 标准差：**24.2**。
- 变异系数 CV：**0.56**。
- 25% 分位：**25**。
- 75% 分位：**57**。
- 90% 分位：**75**。

按“每篇文章先单独统计，再看文章之间分布”计算，平均句长的中间 50% 大致落在 **39.3–49.0**，句长标准差的中间 50% 约为 **18.7–25.8**。典型状态是**中长句为主体，同时保留明显句长波动**。

### 软目标区间

- 平均句长通常约 **36–50**。
- 中位句长通常约 **32–44**。
- 句长标准差通常约 **18–28**。
- CV 通常约 **0.45–0.65**。

题材需要更快动作或更多对话时允许偏短；连续材料/环境推导时允许偏长。不要为了命中区间机械改句。

## 短句密度

全语料中：

- `<= 8` 字：**1.1%**。
- `<= 12` 字：**3.9%**。
- `<= 15` 字：**7.8%**。
- `<= 20` 字：**15.1%**。
- `>= 45` 字：**40.6%**。
- `>= 60` 字：**22.5%**。

“短句有存在感”不等于“短句很多”。真正极短的句子很少，所以才能形成强调。

建议：

- `<=15` 字句子通常保持在 **5–15%** 左右。
- 若整篇超过 **20%**，检查是否碎句化。
- 若 `<=20` 字句子超过 **30%**，通常已经明显偏短促。

## 长句与句内展开

约 **40.6%** 的句子达到 45 字以上，约 **22.5%** 达到 60 字以上。长句常用于：

- 把环境、动作、湿度、材料变化串在同一因果链中。
- 先给条件，再修正，再补角色变量。
- 把视觉、触觉和气味放进同一连续过程。

全语料平均每句约有 **2.87 个逗号**；粗略按逗号、分号、冒号划分，平均约 **3.9 个分句单元**。不要为了“清晰”把所有复句拆成多个独立短句。

## 句长方差

标准差约 24、CV 约 0.56。典型状态更像：

`较长解释句 -> 中等动作句 -> 偶尔短落点 -> 新的中长句`

而不是连续短句，也不是所有句子都被修成同样长度。

- 标准差明显低于 **15**：检查是否过度整齐。
- 标准差高于 **35**：检查是否在极短句与超长句之间来回跳得过头。

## 段落量化：反模式比均值更重要

原始语料跨越多个写作时期，因此不把平均段长当作目标配额。当前偏好“自然分段”高于历史段落统计。

可用于反模式检测的历史数字：

- `单句且 <=25 字` 的短自然段约占 **15.0%**。
- `长段 -> 短单句段 -> 长段 -> 短单句段` 四段 ABAB 窗口，在 686 段里只出现 **9 次**，约 **1.3 次 / 100 段**。

### v7 全局硬检查

为更早发现“长段 + 单句段 + 长段”的模型节拍，v7 把孤立短段也加入硬检查：

- `S`：单句且 <=30 个有效字符。
- `L`：至少 2 句且 >=60 个有效字符。
- `M`：其他。

检查规则：

1. **isolated L-S-L**：每个都要检查。短中篇（<=40 段）出现 **2 次及以上**，默认视为硬失败；若确实都是独立对话，可人工豁免。
2. **ABAB**：出现 1 次就提示；短中篇出现 **2 次及以上**为硬失败。
3. **短单句段比例**：超过 **20%** 开始提示，超过 **25%** 视为强烈异常。
4. **转折型单句段**：以“不过/但是/当然/那么/可/问题/于是/所以/毕竟”等开头且本身很短的独立段，若反复出现，说明模型把连接词当成换段标记。
5. 即使没有严格命中 ABAB，只要短单句段以近似固定间隔插在长段之间，也应手工重排。

这些是版式反模式，不属于“文艺偏好”或“专业偏好”。

## 标点与转折习惯

以下词在历史语料中确实高频，但只能用来让思路拐弯，不能当作打卡词或换段触发器：

- 不过、但是、当然、毕竟、如果、那么、于是、所以、恐怕、或许、正因如此、不得不说。

句内常使用破折号和省略号进行补充、犹豫、自我修正或突然转向。它们应产生真实语义作用，不要每段固定放一个。

## 使用方式

写完草稿后回答：

1. 是否明显比历史样本更碎？
2. 是否为了避免短句而把所有句子拉成相近长度？
3. 极短句是否真的承担强调？
4. 段落换行是否由语义决定，而不是由长短对比决定？
5. 是否反复出现 L-S-L，即使还没形成完整 ABAB？

若运行环境能执行脚本，必须执行：

```bash
python scripts/style_meter.py --strict <draft.txt>
```

`--strict` 返回非零表示出现全局硬反模式。先修句法和分段，再重新检测；不要把硬失败当成软建议。
