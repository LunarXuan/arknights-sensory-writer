# Arknights Sensory Writer

> 让干员不只“被介绍”，而是从鞋、袜、动作、环境与时间里慢慢显出来。

一个面向《明日方舟》的中文角色感官写作 Skill。它把人物设定、立绘装备、职业活动和环境条件串成一条连续的推导链，再写成有角色辨识度的鞋袜、足部与气味鉴赏，以及从这些细节自然长出来的同人场景。

它追求的不是把感官词汇写得更密，而是回答一个更具体的问题：**为什么偏偏是这个角色，在这套装备和这段经历里，会呈现出这样的状态？**

## 它擅长什么

- **角色先行**：职业、地区、性格、成长经历和当前形态会真正改变后面的穿着条件与人物反应。
- **过程优先**：从“为什么这样穿”写到“怎样活动、哪里先升温、鞋袜如何储存变化、脱下后怎样释放、之后如何清洗或再次穿着”。
- **感官有结构**：区分鞋、袜、足部、材料、环境和时间，不把所有结果压缩成一句“有味道”。
- **研究隐身**：必要时核对角色资料与时装信息，但成文默认不暴露检索过程，而是把已确认的信息融进角色世界。
- **风格可调**：内容组织、感官深度和成人向视角分别控制，互不强行绑定。
- **写完可验**：提供 `style_meter.py`，检查配置泄漏、碎句泛滥、段落轮廓和其他硬性文风问题。

## 最短用法

安装这个 Skill 后，直接给出角色和你想要的方向即可：

```text
写一篇 [干员名] 的默认鉴赏，结合当前形态和时装设定，重点写鞋袜、活动过程与气味变化。
```

也可以用自然语言调整结果：

```text
写得更文艺一些，但感官过程要完整。
专业分析，感官写重一点，不要成人恋物互动。
直接写，别问设置。
```

第一次没有偏好时，Skill 会给出一行简短选项；“默认写”“直接写”会使用均衡、中等、成人恋物关闭的设置。

## 三个独立控制面

| 控制 | 可选方向 | 它改变什么 |
| --- | --- | --- |
| 写作模式 | 文艺 / 均衡 / 专业 | 人物意象、分析深度与同人延伸的比例 |
| 感官强度 | 轻 / 中 / 重 / 极重 | 时间积累、材料残留、环境混味和清洁过程的展开程度 |
| 成人恋物 | 关 / 开 | 是否允许更明显的成人向恋物视角；默认关闭 |

“极重”不等于成人向，“专业”也不等于更露骨。三个控制面分别作用于内容组织、感官密度和安全许可。

## 一条真实的写作推导链

```text
角色身份 / 形态 / 时装
            ↓
鞋型、袜类、材质、固定方式与装备历史
            ↓
职业活动、天气、地面、任务时长与清洁条件
            ↓
温度、湿度、摩擦、贴合与局部压力
            ↓
汗液或潮气、材料气味、环境残留与时间变化
            ↓
脱下、放置、清洗、维护、再次穿着
            ↓
符合角色性格的察觉、处理与同人延伸
```

Skill 内部会把信息分成三层：

- **CANON**：档案、语音、剧情和可靠资料直接支持的设定。
- **VISUAL**：立绘或时装中可以直接观察到的鞋袜、姿势、装备和场景信息。
- **INFERENCE**：建立在前两层之上的文学推演，会用合适的语气与事实区分开。

这样做的目的，是让想象有根，同时不把推演伪装成官方设定。

## 内容边界

成人恋物视角默认关闭。只有在用户明确要求、角色年龄已可靠确认且任务方向合适时，才允许开启；年龄不明或明确未成年角色只保留非性化的装备、工作、环境、清洁和人物叙事。

这是一款角色感官写作工具，不是攻略、数值分析器，也不是把角色资料整页搬进正文的百科摘要器。

## 仓库结构

```text
SKILL.md                       核心行为契约与写作流程
agents/openai.yaml             Skill 展示信息、默认提示与宿主配置
assets/icon.svg                Skill 图标
references/                    模式、事实分层、感官推理与文风资料
scripts/style_meter.py         草稿文风检查器
```

如果想理解“它如何组织内容”，先读 [`SKILL.md`](SKILL.md)；如果想调整某个具体行为，再进入 [`references/`](references/) 找对应规则。

## 草稿检查

对 UTF-8 文本或 Markdown 草稿运行严格检查：

```bash
python scripts/style_meter.py --strict path/to/draft.txt
```

检查器重点关注配置词泄漏、研究痕迹、短单句和机械长短段交替等问题。它是回归工具，不替代对角色事实、因果链和安全边界的人工判断。
